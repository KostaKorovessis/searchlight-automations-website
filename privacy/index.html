Privacy Policy

Effective September 6, 2026

Searchlight Automations is run by Kosta Korovessis. This policy covers this website (searchlightautomations.com), the Routine OS product, and the apps we build for our own use, including the "Searchlight YouTube" app that connects to Google.

What we collect on this website

  • If you fill in a form here, we keep the email address you typed so we can write back to you. Nothing else.
  • If you book a call, Calendly collects your name, email, and the time you picked, under Calendly's own policy. We use it only to run that call and to send you the prep notes for it.
  • We do not run ad trackers. The site is hosted on Netlify, which keeps standard server logs.

The Searchlight YouTube app and Google user data

This app is a tool we use to manage our own YouTube channel. It is not offered to the public. When a Google account signs in to it, the app can:

  • read the channel's details and its analytics,
  • upload videos and set channel art on that channel,
  • read and reply to comments on that channel's videos.

The access token Google issues is stored only on our own computer. It is not sent to any other server, not shared with anyone, and not sold. We use Google data only to run the channel it belongs to. We do not use it for ads, and we do not build profiles from it. You can remove the app's access at any time at myaccount.google.com/permissions.

Our use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Sharing

We do not sell your data. We do not share it with anyone except the services named above that we need to run the site and the calls, and only for that purpose.

Keeping and deleting

We keep an email address until you ask us to remove it. Write to us and it is gone. Google access tokens are deleted when we revoke the app or delete the file that holds them.

Changes

If this policy changes, the new version goes on this page with a new date.
